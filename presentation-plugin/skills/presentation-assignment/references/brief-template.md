## General rubric (used when none is given)

| Kriteria | Yang diperiksa |
|---|---|
| Isi dan ketepatan | Facts correct and sourced; covers the topic the assignment names |
| Struktur | Clear opening, logical order, conclusion that answers the aim |
| Sumber | Recent, credible, cited on the slide where used, reference list complete |
| Desain slide | One idea per slide, readable, visuals support the point |
| Penyampaian | Fits the time, notes explain rather than repeat the slide |
| Tanya jawab | Ready for likely questions |
